# Steuerzeichen-Demo

Oeffnen im Browser (deutsche Oberflaeche):

https://vscode.dev/github/BENUTZER/REPO?vscode-lang=de

(BENUTZER und REPO ersetzen.)

- `.vscode/settings.json`: Steuerzeichen und Whitespace sichtbar
- `.gitattributes`: verhindert, dass Git Zeilenenden umwandelt
- `01`-`03`: je ein Zeilenende-Typ (siehe Statusleiste unten rechts: CRLF / LF / CR)
- `04`: viele Steuerzeichen
- `05`: enthaelt NUL, VS Code kann sie als Binaerdatei behandeln ("Trotzdem oeffnen")
